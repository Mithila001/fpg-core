# fpg-core documentation

The canonical consumer reference is [PACKAGE_FEATURE_REFERENCE.md](PACKAGE_FEATURE_REFERENCE.md).
It is derived from the current package exports and source contracts and documents
each feature independently. The other files in this directory are focused migration,
installation, or historical design notes and may apply only to the version named in
their title.

When a public feature changes, update the canonical reference by following
`src/fpg_core/Package_Documentation_Template.md`.
