# Adaptable Lab workspaces

**Accepted.** Start with the shared result workspace, a dominant task area and
a narrower context panel. A table or editor may be the main area; a canvas and
separate setup/result pages are not required. Keep repeated selections visible
when practical and place infrequent actions in secondary surfaces.

Room colors represent room types across views. Labels identify instances;
status and diagnostic colors retain their separate meanings. This supports
comparison without imposing a generic experiment lifecycle.
